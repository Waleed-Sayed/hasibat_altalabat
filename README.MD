تطبيق أندرويد (حاسبة الطلبات) مخصص لمساعدة مناديب التوصيل على تسجيل طلباتهم اليومية وحساب دخلهم ومستحقاتهم بدقة. يدعم التطبيق حساب الدخل التراكمي بناءً على شرائح الأسعار المخصصة، وحساب البونص وبدل البنزين تلقائياً (بثلاثة مستويات)، مع عرض كشوفات وتقارير مفصلة شهرياً وسنوياً، وإمكانية تصدير التقارير وحفظها في الجهاز أو مشاركتها مباشرة كملف PDF، بالإضافة إلى ميزة النسخ الاحتياطي واستعادة البيانات محلياً بدون إنترنت.
An Android app designed for delivery drivers to track daily orders and calculate earnings automatically. Features customizable pricing tiers, 3-level bonus & fuel allowance calculations, monthly and annual financial summaries, local JSON backup/restore, and full PDF report export, saving, and sharing.
